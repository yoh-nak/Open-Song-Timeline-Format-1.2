# OSTF v1.2 — हिन्दी

OSTF v1.2 गीत की संरचना, ताल-मात्रा, टेम्पो, की और कॉर्ड प्रगति साझा करने का प्रारूप है।

`.ostf` फ़ाइल UTF-8 JSON है। `examples/` देखें और `python tests/validate_ostf.py examples/*.ostf` चलाएँ।

इसमें MIDI प्रदर्शन या UI सेटिंग नहीं हैं; सभी DAW या v1.1 के साथ पूर्ण संगतता प्रमाणित नहीं है।
