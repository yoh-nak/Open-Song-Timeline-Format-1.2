# OSTF v1.2 — 简体中文

OSTF v1.2 是交换乐曲结构、拍号、速度、调式和和弦进程的格式。

`.ostf` 文件是 UTF-8 JSON。请查看 `examples/` 并使用 `python tests/validate_ostf.py examples/*.ostf` 验证。

不包含 MIDI 演奏事件或界面设置；不保证与所有 DAW 或 v1.1 完全兼容。
