# OSTF v1.2 — 한국어

OSTF v1.2는 곡 구조, 박자, 템포, 조성, 코드 진행을 교환하는 규격입니다.

`.ostf` 파일은 UTF-8 JSON입니다. `examples/`를 참고하고 `python tests/validate_ostf.py examples/*.ostf`로 검사하세요.

MIDI 연주 데이터와 UI 설정은 제외됩니다. 모든 DAW 및 v1.1과의 완전한 호환은 보장하지 않습니다.
