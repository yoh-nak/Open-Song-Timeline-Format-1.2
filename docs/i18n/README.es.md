# OSTF v1.2 — Español

OSTF v1.2 permite intercambiar estructura musical, compás, tempo, tonalidad y acordes.

Los archivos `.ostf` son JSON UTF-8. Consulte `examples/` y valide con `python tests/validate_ostf.py examples/*.ostf`.

No incluye interpretación MIDI ni ajustes de interfaz. No se garantiza compatibilidad total con DAW o v1.1.
