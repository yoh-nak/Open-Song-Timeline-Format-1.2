# OSTF v1.2 — العربية

OSTF v1.2 صيغة لتبادل بنية العمل الموسيقي والميزان والسرعة والمقام وتسلسل التآلفات.

ملفات `.ostf` هي JSON بترميز UTF-8. راجع `examples/` وتحقق بالأمر `python tests/validate_ostf.py examples/*.ostf`.

لا تتضمن بيانات أداء MIDI أو إعدادات الواجهة. لم تُعتمد توافقية شاملة مع DAW أو الإصدار 1.1.
