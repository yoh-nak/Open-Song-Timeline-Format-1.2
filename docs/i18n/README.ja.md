# OSTF v1.2 — 日本語

OSTF v1.2は楽曲構造・拍子・テンポ・調性・コード進行を交換する規格です。

`.ostf`ファイルはUTF-8のJSONです。`examples/`のサンプルを参照し、`python tests/validate_ostf.py examples/*.ostf` で検証してください。

MIDI演奏情報・UI設定は対象外です。DAWや旧v1.1との完全互換性は保証していません。
