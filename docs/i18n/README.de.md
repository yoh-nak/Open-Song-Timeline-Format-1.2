# OSTF v1.2 — Deutsch

OSTF v1.2 tauscht Songstruktur, Taktarten, Tempo, Tonarten und Akkorde aus.

`.ostf`-Dateien sind UTF-8-JSON. Beispiele unter `examples/`; Prüfung: `python tests/validate_ostf.py examples/*.ostf`.

Keine MIDI-Performance- oder UI-Daten; DAW- und v1.1-Vollkompatibilität ist nicht zertifiziert.
