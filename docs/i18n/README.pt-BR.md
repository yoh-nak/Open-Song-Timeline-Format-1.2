# OSTF v1.2 — Português (Brasil)

OSTF v1.2 intercambia estrutura musical, compassos, andamento, tonalidades e acordes.

Os arquivos `.ostf` são JSON UTF-8. Veja `examples/` e valide com `python tests/validate_ostf.py examples/*.ostf`.

Não inclui execução MIDI nem configurações de interface; interoperabilidade DAW/v1.1 não certificada.
