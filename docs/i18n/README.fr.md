# OSTF v1.2 — Français

OSTF v1.2 échange la structure musicale, les mesures, le tempo, la tonalité et les accords.

Les fichiers `.ostf` sont en JSON UTF-8. Voir `examples/` puis vérifier avec `python tests/validate_ostf.py examples/*.ostf`.

Pas de données de performance MIDI ni d’interface ; compatibilité DAW/v1.1 non certifiée.
