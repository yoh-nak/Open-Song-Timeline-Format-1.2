# OSTF v1.2 — 繁體中文

OSTF v1.2 用於交換樂曲結構、拍號、速度、調性與和弦進行。

`.ostf` 為 UTF-8 JSON。請參閱 `examples/`，以 `python tests/validate_ostf.py examples/*.ostf` 驗證。

不包含 MIDI 演奏事件或介面設定；不保證與所有 DAW 或 v1.1 完全相容。
